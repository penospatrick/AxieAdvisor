# Axie Classic Battle Advisor — Android prototype v0.1

An independent fan-made manual battle helper. This is not affiliated with Axie Infinity.

## Current features
- Movable floating AI bubble (with Android overlay permission)
- Basic manual energy-budget card selection calculator
- GitHub Actions debug APK build

## Not implemented
- Automatic screen capture or card recognition
- Full battle-rule modeling or win prediction
- Floating recommendation panel

## Build
Go to Actions → Build Android APK → Run workflow, then download the debug APK artifact.
